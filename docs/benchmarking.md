# Benchmarking

Benchmark-only material is isolated under `benchmarks/`.

- `benchmarks/compare_cellstates_simulation.py`
- `benchmarks/run_triplicate_partition_benchmark.py`
- `benchmarks/data/`
- `benchmarks/results/`
- `benchmarks/reports/`

Upstream reference code is isolated under:

- `reference/cellstates/`

Normal users should ignore both `benchmarks/` and `reference/` and use only:

- `mcellstate`
- `mcellstate_doublet`
- `scripts/run_rnamatrix_batch.py`
